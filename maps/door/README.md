# maps/door/ —— 门区域裁剪图（只用于识别）

把每张地图上"门"那一小块原样截出来放这里，文件名要和 `maps/full/`（或 `maps/` 根目录）里
对应的完整地图**同名**，例如 `door/map1.jpg` ↔ `full/map1.jpg`。

要点：

- **宽高比**要接近 `door_coords` 的 583:300 ≈ 1.94（像素尺寸多大都行，反正会归一化到 128×128）。
- **不要**把整张地图放进来——这里的图会被直接当成门区域特征，程序不会再裁一次。
  放整图进来的话，识别会拿"整张地图"去比对"屏幕上的门区域"，必然对不上。

详细说明见上一级目录的 `maps/README.md`。

（本文件是 .md，不会被当成模板加载。）
